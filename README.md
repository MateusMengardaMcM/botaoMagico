
# Botão Mágico

Projeto voltado para fins educacionais, com intenção de aprender javascript, focando nos conceitos de eventos e boas práticas.


## Aprendizados

Compreendi os conceitos de eventos e boas práticas no javascript.
## Funcionalidades

- Voce pode clicar no botao, dai ele muda de cor =).

## Stack utilizada

**Front-end:** Html, css &JavaScript.



## Deploy

Para fazer o deploy desse projeto faça um clone do repositório e execute o arquivo em index.html.

```bash
  git clone https://github.com/MateusMengardaMcM/botaoMagico
```
